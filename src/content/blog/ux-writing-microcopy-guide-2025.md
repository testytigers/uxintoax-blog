## The Short Answer

UX writing is the text users see in your product.

A button. An error message. A label. An empty state.

Every word you write either helps the user or gets in their way.

---

## The 5 Principles of UX Writing

### 1. Be Clear
Plain language. No jargon. No cleverness. If a 12-year-old can't understand it, rewrite it.

### 2. Be Concise
Less is more. Every word should earn its place. If you can say it in fewer words, do it.

### 3. Be Helpful
Guide users. Solve their problems. Anticipate their questions.

### 4. Be Consistent
Same terminology everywhere. Same tone everywhere. Same structure everywhere.

### 5. Be Human
Write like you speak. Use "you" and "we." Show personality, not robotic language.

---

## Writing Each Component

### Buttons
- **Good:** "Sign Up" / "Get Started"
- **Bad:** "Click Here" / "Submit"

### Error Messages
- **Good:** "Your password needs 8+ characters"
- **Bad:** "Error 404" / "Invalid input"

### Form Labels
- **Good:** "Email address"
- **Bad:** "Enter email" / "Input"

### Empty States
- **Good:** "You haven't created a project yet. Get started by clicking below."
- **Bad:** "Nothing to display"

### Tooltips
- **Good:** "This helps us personalize your recommendations"
- **Bad:** "(i)" / "?"

---

## Real Examples

### Before (Bad)
```
Submit
Error: Invalid format
Continue
```

### After (Good)
```
Get Started
"Your email needs to include @ — like hello@example.com"
Keep Going
```

## The UX Writing Checklist

- [ ] Every button uses action verbs
- [ ] Error messages explain the problem and solution
- [ ] Form labels are descriptive
- [ ] Empty states guide users forward
- [ ] Tooltips explain why, not just what
- [ ] No jargon or technical terms
- [ ] Tone matches your brand
- [ ] Tested with real users

---

## The Bottom Line

UX writing isn't decoration. It's a critical part of the user experience. Every word you write shapes how users feel about your product. Write clearly. Write concisely. Write helpfully.
