## The Short Answer

A UX audit is a health check for your product's user experience.

It tells you what's broken, what's working, and what to fix first.

---

## The 3 Phases of a UX Audit

### Phase 1: Discovery (Week 1)
- Define scope and goals
- Gather baseline metrics
- Review analytics data
- Collect user feedback

### Phase 2: Evaluation (Week 2-3)
- Heuristic analysis
- Usability testing
- Accessibility review
- Competitive comparison

### Phase 3: Reporting (Week 4)
- Prioritize findings
- Create recommendations
- Present to stakeholders
- Define next steps

---

## Heuristic Evaluation Framework

### Nielsen's 10 Heuristics
1. System matches real world
2. System is consistent
3. System is recoverable (undo/redo)
4. System is predictable
5. System is simple and clean
6. Recognition over recall
7. Flexibility and efficiency
8. Aesthetic and minimalist
9. Help users recover from errors
10. Help and documentation

## What to Evaluate

### Visual Design
- Consistency
- Hierarchy
- Spacing
- Typography
- Color

### Navigation
- Clarity
- Consistency
- Findability
- Information architecture

### Content
- Clarity
- Tone
- Scannability
- Relevance

### Interactions
- Feedback
- States
- Animations
- Responsiveness

### Accessibility
- WCAG compliance
- Keyboard navigation
- Screen reader support
- Color contrast

## The UX Audit Checklist

- [ ] Define scope and goals
- [ ] Gather baseline metrics
- [ ] Walk through user flows
- [ ] Heuristic evaluation
- [ ] Usability testing (5+ users)
- [ ] Accessibility review
- [ ] Competitive analysis
- [ ] Prioritize by severity
- [ ] Create actionable recommendations
- [ ] Present findings with evidence

---

## The Bottom Line

A UX audit turns subjective opinions into objective findings. Systematic evaluation. Evidence-based recommendations. Clear prioritization. Your stakeholders will thank you.
